# Перенос мониторинга жилья в Потсдамбот

## Цель

Оставить один пользовательский Telegram-бот — `@Potsdambot`. Сборщики Immowelt и ProPotsdam остаются внутренними компонентами, а старый `@Wohnungcheckpotsdam_bot` выводится из эксплуатации без потери фильтров, истории и дедупликации.

## Установленные владельцы Telegram ID

- `312029534` — основной аккаунт Артёма.
- `5115109366` — второй аккаунт Артёма.
- `544675510` — Катя, жена Артёма.

## Что можно удалить только после завершения переноса

- остановленный контейнер `check-wohnung-bot-1`;
- старый Docker-образ квартирного бота;
- Telegram-бот `@Wohnungcheckpotsdam_bot` и его токен;
- старую polling-часть `C:\opt\check-Wohnung\app\main.py`;
- старый Docker-запуск после отделения общего приёмника.

## Что сохраняется

- `C:\opt\check-Wohnung` как общий приёмник и хранилище Immowelt;
- `C:\opt\check-Wohnung\data\listings.db`;
- приёмник `127.0.0.1:18765`;
- Chrome-расширение `C:\Users\Admin\Desktop\check-Wohnung-extension` и его автозапуск;
- сборщик ProPotsdam на `127.0.0.1:18766`;
- база Потсдамбота `/app/config/bot.db`.

## Порядок выполнения

### 1. Исправить архитектурные недостатки

1. Перевести отправку новых объявлений Immowelt со старого токена на внутренний HTTP-приёмник Потсдамбота.
2. Оставить один рабочий путь ProPotsdam: планировщик Потсдамбота → порт `18766` → `bot.db`; убрать параллельную отправку через `18765`.
3. Сделать ограничения Immowelt независимыми для каждого фильтра, а не общими для всех пользователей.
4. Добавить безопасную начальную базу для каждого нового фильтра ProPotsdam без рассылки текущих объявлений.
5. Изолировать ошибку одного Immowelt-фильтра от остальных фильтров и источников расширения.
6. Показывать каждому пользователю состояние только его фильтров.

### 2. Создать резервные копии

- проверить целостность и скопировать `listings.db`;
- проверить целостность и скопировать `/app/config/bot.db` из Docker-тома;
- проверить возможность чтения обеих копий.

### 3. Подготовить Катю

- использовать Telegram ID `544675510`;
- Катя открывает `@Potsdambot` и нажимает `/start`;
- согласовать её параметры Immowelt и ProPotsdam перед созданием фильтров.

### 4. Создать фильтры

- создать отдельные фильтры Кати;
- не копировать автоматически фильтр второго аккаунта Артёма `5115109366`;
- сначала сохранить текущие результаты как начальную базу без уведомлений.

### 5. Проверить в течение суток

- Immowelt запускается каждые 15 минут;
- ProPotsdam запускается каждые 30 минут;
- уведомления приходят от `@Potsdambot` правильному владельцу;
- текущие объявления не рассылаются как новые;
- нет повторных уведомлений;
- статус каждого пользователя показывает только его фильтры.

### 6. Вывести старого бота из эксплуатации

Только после успешной проверки:

1. отозвать старый токен;
2. удалить `check-wohnung-bot-1` и старый образ;
3. удалить старую polling-часть и Docker-запуск;
4. повторно проверить порты `18765`, `18766`, контейнер `tgbot`, меню и реальные уведомления.

## Правила безопасности

- Не удалять и не отзывать старый токен до доказанной отправки Immowelt через Потсдамбот.
- Не раскрывать токены, пароли ProPotsdam и cookies в журналах или Git.
- Все изменения выполнять через TDD: падающий тест → минимальное исправление → полный набор тестов → отдельный commit.
- Каждый этап завершать фактической проверкой работающего пути, а не только чтением конфигурации.
