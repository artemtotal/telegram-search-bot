# Жильё: Берлин и Бранденбург — план по этапам

Начато 02.11.2026 по просьбе Артёма: искать жильё не только в Потсдаме, а во всём
Бранденбурге и в Берлине, на всех основных массовых площадках. Место — город или
индекс, по желанию с радиусом, как на Immowelt. Кооперативы — последними.

## Как устроено «где искать» (общее для всех этапов)

- Условие поиска `criteria["area"]` (модуль `user_jobs/housing_area.py`):
  `{"kind": "city"|"plz", "name", "code", "kreis", "plz", "radius_km"}`.
  Пусто (None) — «только Потсдам»: так ведут себя все старые фильтры, у них ничего
  не меняется.
- Справочник — `user_jobs/geo_plz_be_bb.tsv`: индексы Берлина и Бранденбурга с
  координатами (GeoNames, CC BY 4.0). Крупные города (Berlin, Potsdam, Cottbus,
  Brandenburg an der Havel, Frankfurt (Oder)) собраны целиком, служебные индексы
  фирм выкинуты.
- Квартира попадает в место по индексу: «только город» — индексы города; с
  радиусом — индексы ближе R км к любой точке города. Радиусы: 0/5/10/20/30/50.
- Ввод: кнопки «Potsdam» / «Berlin» или текстом город/индекс (любое написание,
  кириллица тоже: «Фалькензее», «Берлін»). Несколько совпадений — кнопки с округом
  (два Werder различаются по округу). Индекс Потсдама превращается в «Потсдам»
  (там есть районы).
- Карточка фильтра: первая строка «📍 Где». Районы — только для самого Потсдама.
  Новый фильтр сначала спрашивает место, Jobcenter — только для Потсдама (лимиты в
  боте потсдамские).
- Площадки, которые ещё не умеют искать вне Потсдама, у такого фильтра просто не
  создаются; что человек выключил сам — помнится в `criteria["sources_off"]` и
  возвращается, когда место снова Потсдам.

### Этап 1 — что сделано (02.11.2026)

- ImmoScout24 (API приложения) читает ещё `/de/berlin/berlin` (≈4700 квартир,
  94 стр.) и `/de/brandenburg` (≈2400, 48 стр.). Каждые 15 минут — только новые
  страницы (до первой страницы без новых), раз в 4 часа — вся выдача одного
  региона, чтобы отметить снятые. Потсдам читается как раньше, целиком.
- Снятые отмечаются по регионам: частичный обход Берлина не «снимает» остальной
  Берлин, потсдамский обход — берлинские.
- Карточку объявления (полная аренда, галерея) вне Потсдама читаем только у свежих
  (до 2 суток) квартир, которые хоть кому-то подходят по выдаче — их тысячи.
- Включается для всех переменной `HOUSING_PLACE_FOR_ALL=1` в `.env` (без неё
  строка «📍 Где» и вопрос места видны только админу). Регионы ImmoScout24 —
  `IMMOSCOUT_REGIONS` (по умолчанию `berlin,brandenburg`).

### Этап 2 — заметки на будущее

- Kleinanzeigen: `s-wohnung-mieten/berlin/c203l3331`, `s-wohnung-mieten/brandenburg/c203l2`
  отвечают обычным HTML (проверено 02.11). Сейчас монитор берёт Потсдам с радиусом и
  отсеивает «не Потсдам» — для региона нужны индексы в записи и обход как у ImmoScout24.
- Потсдамские агентства (ProPotsdam, Semmelhaack, SCHOBA, ImmoTeam, locals, Karl Marx)
  сейчас работают, только если место — сам Потсдам (с радиусом или без). Чтобы
  «Werder + 10 км» получал и их, им нужна та же проверка индекса в сопоставлении.

### Этап 4 — Vonovia

`/api/real-estate/list?city=Berlin` отдаёт берлинские квартиры (проверено 02.11);
`city=Brandenburg` и пустой город — ничего. Нужен список городов Бранденбурга, где у
Vonovia есть фонд, и обход по каждому.

### Этап 10 — сайт для подписчиков

Кнопка «🌐 Сайт» в боте только у платных; вход по одноразовой ссылке из бота (как
portal-link у Автоцеха), без паролей. На сайте: свои фильтры (создать/изменить),
вкл/выкл по площадкам, статистика (сколько пришло, откуда, сколько уже сняли),
история «куда откликался» (письма из «✍️ Лист»). Домен — решить на этом этапе:
бесплатный поддомен (eu.org, duckdns) или свой недорогой `.de`.
