# Жильё: Берлин и Бранденбург — план по этапам

Начато 02.11.2026 по просьбе Артёма: искать жильё не только в Потсдаме, а во всём
Бранденбурге и в Берлине, на всех основных массовых площадках. Место — город или
индекс, по желанию с радиусом, как на Immowelt. Кооперативы — последними.

## Как устроено «где искать» (общее для всех этапов)

- Условие поиска `criteria["area"]` (модуль `user_jobs/housing_area.py`):
  `{"kind": "city"|"plz", "name", "code", "kreis", "plz", "radius_km"}`.
  Пусто (None) — «только Потсдам»: так ведут себя все старые фильтры, у них ничего
  не меняется.
- Справочник — `user_jobs/geo_plz_be_bb.tsv`: индексы Берлина и Бранденбурга с
  координатами (GeoNames, CC BY 4.0). Крупные города (Berlin, Potsdam, Cottbus,
  Brandenburg an der Havel, Frankfurt (Oder)) собраны целиком, служебные индексы
  фирм выкинуты.
- Квартира попадает в место по индексу: «только город» — индексы города; с
  радиусом — индексы ближе R км к любой точке города. Радиусы: 0/5/10/20/30/50.
- Ввод: кнопки «Potsdam» / «Berlin» или текстом город/индекс (любое написание,
  кириллица тоже: «Фалькензее», «Берлін»). Несколько совпадений — кнопки с округом
  (два Werder различаются по округу). Индекс Потсдама превращается в «Потсдам»
  (там есть районы).
- Карточка фильтра: первая строка «📍 Где». Районы — только для самого Потсдама.
  Новый фильтр сначала спрашивает место, Jobcenter — только для Потсдама (лимиты в
  боте потсдамские).
- Площадки, которые ещё не умеют искать вне Потсдама, у такого фильтра просто не
  создаются; что человек выключил сам — помнится в `criteria["sources_off"]` и
  возвращается, когда место снова Потсдам.

### Этап 1 — что сделано (02.11.2026)

- ImmoScout24 (API приложения) читает ещё `/de/berlin/berlin` (≈4700 квартир,
  94 стр.) и `/de/brandenburg` (≈2400, 48 стр.). Каждые 15 минут — только новые
  страницы (до первой страницы без новых), раз в 4 часа — вся выдача одного
  региона, чтобы отметить снятые. Потсдам читается как раньше, целиком.
- Снятые отмечаются по регионам: частичный обход Берлина не «снимает» остальной
  Берлин, потсдамский обход — берлинские.
- Карточку объявления (полная аренда, галерея) вне Потсдама читаем только у свежих
  (до 2 суток) квартир, которые хоть кому-то подходят по выдаче — их тысячи.
- Включается для всех переменной `HOUSING_PLACE_FOR_ALL=1` в `.env` (без неё
  строка «📍 Где» и вопрос места видны только админу). Регионы ImmoScout24 —
  `IMMOSCOUT_REGIONS` (по умолчанию `berlin,brandenburg`).

### Этап 2 — что сделано (02.11.2026)

- **Kleinanzeigen** читает ещё `s-wohnung-mieten/berlin/c203l3331` и
  `s-wohnung-mieten/brandenburg/c203l7711` (коды — из `/s-ort-empfehlungen.json`
  сайта; `l2` оказался Бременом). Раз в 20 минут, как и Потсдам: первая страница,
  вторая — только если на первой ≥15 новых. Квартиры региона сверяются по индексу,
  а не по «город = Потсдам». Страницу объявления (полная аренда, фото) читаем только
  тем, кто кому-то подходит, — не больше 10 за обход. Снятой квартира региона
  считается, если её 3 дня не видно на первых страницах (иначе бесплатным с
  задержкой 2 ч не доходило бы ничего — берлинская страница меняется за часы).
- **Место — во всех площадках бота** (`area` в записях Semmelhaack, SCHOBA, ImmoTeam,
  locals, Karl Marx, Vonovia, ProPotsdam, Kleinanzeigen): каждое `matches_filter`
  сперва проверяет индекс квартиры. Поэтому «Werder + 10 км» получает и потсдамские
  агентства, но только ближнюю часть Потсдама (14469 — да, 14480 — нет).
- **Immowelt** — только когда место сам Потсдам: его фильтры живут в check-Wohnung и
  места не знают (этап 3). Кооперативы и лимиты Jobcenter — тоже только Потсдам.
- Регионы Kleinanzeigen — `KLEINANZEIGEN_REGIONS` (по умолчанию `berlin,brandenburg`).

### Этап 4 — Vonovia

✅ Сделано 02.11.2026. API ищет только по точному названию города (`city=Brandenburg` и
пустой город — ничего, радиуса нет). Проверено 40 городов: квартиры есть в Берлине (15),
Бранденбурге-на-Хафеле (4), Ораниенбурге, Эберсвальде, Зенфтенберге (по 1). Обход раз в
15 минут: Потсдам как раньше + `REGION_CITIES` в `vonovia_parser` (эти пять + Cottbus,
Frankfurt (Oder), Falkensee, Bernau, Königs Wusterhausen), каждый город целиком; снятые —
только в своём городе (`vonovia_listing.region`). Переопределить список —
`VONOVIA_REGION_CITIES="Berlin|Cottbus|…"`. Раз в пару месяцев стоит перепроверить
40 городов — новые могут появиться.

### Этап 10 — сайт для подписчиков

Кнопка «🌐 Сайт» в боте только у платных; вход по одноразовой ссылке из бота (как
portal-link у Автоцеха), без паролей. На сайте: свои фильтры (создать/изменить),
вкл/выкл по площадкам, статистика (сколько пришло, откуда, сколько уже сняли),
история «куда откликался» (письма из «✍️ Лист»). Домен — решить на этом этапе:
бесплатный поддомен (eu.org, duckdns) или свой недорогой `.de`.

### Этап 5 — Jobcenter (Берлин сделан 02.11.2026)

- `user_jobs/jobcenter_tables.py`: Берлин — AV-Wohnen с 01.01.2026 (памятка Jobcenter
  Treptow-Köpenick): Bruttokalt 449,00 / 543,40 / 668,80 / 752,40 / 903,72 € на 1–5
  человек, +106,32 € за каждого следующего.
- Тёплая граница = Bruttokalt + Grenzwert Heizkosten «Erdgas, дом 251–500 м²»
  (123,50 / 160,55 / 197,60 / 222,30 / 251,94 €, +29,64 €). Настоящий предел зависит
  от площади дома и топлива — это середина таблицы.
- Новый фильтр спрашивает Jobcenter для Потсдама и Берлина (с радиусом тоже), кнопка
  лимита в ценах — там же. Для остальных мест вопроса нет.
- Осталось: округа Бранденбурга (Potsdam-Mittelmark, Havelland, Teltow-Fläming,
  Oberhavel, Barnim, Märkisch-Oderland, Oder-Spree, Dahme-Spreewald, …) — у каждого своя
  Richtlinie KdU, часто с несколькими Vergleichsräume; нужна выверка по первоисточникам.

### Этап 3 — Immowelt (02.11.2026)

- **Без браузера.** Страница поиска Immowelt отдаётся обычному GET (403 — только у
  Exposé), все карточки лежат в ней JSON-ом, сжатым LZString
  (`window["__UFRN_FETCHER__"]` → `classified-serp-init-data`). check-Wohnung
  (`app/immowelt_http.py`) раз в 15 минут сам читает страницы и отдаёт карточки в тот
  же `_receive_wide`, что раньше получал их от расширения Chrome; расширению Immowelt
  больше не выдаётся (`IMMOWELT_HTTP=0` вернёт старый путь). Ключ карточки — из её
  `url` (у старых объявлений uuid, у новых короткий id): на живой странице все 30
  карточек совпали с каталогом, без повторной рассылки.
- **Регионы.** После Потсдама — Берлин (`locations=AD04DE11`, ≈1640) и Бранденбург
  (`AD04DE12`, ≈1420), только если есть фильтры с местом. Первый обход региона читает
  всё и лишь запоминает, дальше — новые страницы.
- **Место** приходит из бота в теле запроса (`area`), хранится в
  `housing_filters.area`; решает копия `housing_area.py` + справочник индексов в
  `check-Wohnung/app` — **править вместе с ботом**.

### Этап 8 — inberlinwohnen.de (02.11.2026)

- Новая площадка `inberlin` (`user_jobs/inberlin_*`): общий портал шести городских
  компаний Берлина, ≈950 квартир. `GET /wohnungsfinder/?page=N`, 10 на страницу, новые
  первыми; у каждой карточки JSON в `wire:snapshot` (Kaltmiete, Gesamtmiete с отоплением
  из деталей, комнаты, площадь, индекс, район, компания, WBS, ссылка на объявление
  компании, фото).
- Раз в 15 минут — новые страницы до первой без новых; раз в 6 часов — все (снятые).
  Самый первый обход — база (никому не шлёт).
- Только для мест, где есть хоть часть Берлина (`housing_area.touches_berlin`); у фильтров
  Потсдама её нет и «все N порталов» её не считают.
- В сообщении — компания и WBS («nicht erforderlich» / «WBS ab 160 erforderlich»).
  **Дальше:** выбор «WBS у меня есть / нет» в карточке — сейчас приходят и квартиры с WBS
  (на 02.11 — 4 из 10).

### Этап 7 — округа Берлина и WBS (02.11.2026)

- `user_jobs/geo_berlin_bezirke.tsv`: индекс → округ (12 Bezirke) — центр индекса
  (GeoNames) внутри границ округов (Geoportal Berlin, ALKIS Bezirke). Сверено на 475
  квартирах inberlinwohnen: 474 совпали, 12107 лежит на границе.
- Место «Берлин, только город» может хранить `bezirke`; `housing_area.allowed_plz`
  оставляет индексы этих округов — работает сразу на всех площадках и в check-Wohnung
  (копия модуля и таблицы там).
- В карточке для Берлина — кнопка «🏙 Райони», как у Потсдама; в строке места —
  «Berlin (Mitte, Pankow)».
- **WBS** (`housing_wbs`): «🪪 WBS: не важно / нет / WBS 100…220» в карточке и
  вопрос в новом фильтре после Jobcenter. Каждая площадка проверяет его первым делом
  (поле портала или заголовок: «nur mit WBS», «WBS ab 160 erforderlich», «ohne WBS»).

### Этап 5 — округа Бранденбурга (02.11.2026)

- В `jobcenter_tables.KREIS_TABLES` — действующие официальные таблицы Bruttokaltmiete:
  Havelland (gültig ab 01.01.2026: Ost / Mitte / West), Potsdam-Mittelmark (GA 62-1,
  Stand 01.01.2026: Planregion 1–4, 5+ человек — €/м² × площадь), Oberhavel
  (Handlungsrichtlinie vom 05.11.2024: четыре рынка). Места привязаны по названию из
  справочника индексов, вместе с частями общин (Elstal, Bergholz-Rehbrücke…).
- Тёплая граница — Bruttokalt + отопление «газ, дом 250–500 м²» (22,30 €/м² в год ×
  положенная площадь, из таблицы Havelland).
- **Не нашлось** действующих официальных цифр: Teltow-Fläming (на сайте — 2018),
  Dahme-Spreewald (суммы в отдельном приложении), Barnim, Märkisch-Oderland, Oder-Spree,
  Brandenburg an der Havel, Cottbus, Frankfurt (Oder) — там вопроса Jobcenter нет.
